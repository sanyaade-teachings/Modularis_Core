# Серый MLGamer - Модулярис тест (0.0.0pre-alpha ремикс)

![Проигрыватель](../share/player.png)

Это музыкальное произведение написано на языке программирования C на основе новейшей версии свободного каркаса Модулярис Ядро &mdash; 0.0.0pre-alpha! Это часть серии ремиксов &laquo;гимна&raquo; тестирования Модуляриса.
Наконец-то я доработал функционал каркаса до того, что с её помощью теперь возможно сделать какую-то стоящую музыку. Но, конечно, есть ещё к чему стремиться. Недостаток функционала синтеза звука скомпенсирован сэмплами. Вообще хотел сделать из этого &laquo;гимна&raquo; что-то типа House-попсни, но опять же не хватило звуков, поэтому Happy Hardcore и мешанина звуков, чтобы базовые волноформы сильно не выпирали.

P. S. Произведение портировано на каркас Модулярис Ядро версии 0.0.0pre.

Инструкция по сборке этой программы находится в файле &laquo;[../README.md](../README.md)&raquo;.

Приятного прослушивания!
